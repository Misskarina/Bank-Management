# Bank Management System

A full-stack **Bank Management System** built with **Spring Boot 3**, **Java 17**, and **Thymeleaf**.  
Includes a **manager-facing dashboard** and a complete **REST API** for account management.

---

## Features
- Full CRUD for bank accounts (Create, View, Delete)  
- Manager Dashboard with Tailwind CSS styling  
- REST API for programmatic access (Postman-ready)  
- MariaDB support (H2 for testing)  
- Clean service-layer & DTO architecture  

---

## Tech Stack
- **Backend**: Spring Boot 3, Java 17  
- **Frontend**: Thymeleaf + Tailwind CSS  
- **Database**: MariaDB / H2  
- **ORM**: Spring Data JPA (Hibernate)  
- **Build**: Maven
